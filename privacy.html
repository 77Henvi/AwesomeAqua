Awesome Aqua ("เรา") ให้ความสำคัญกับความเป็นส่วนตัวของลูกค้าและผู้ใช้งานทุกคน เอกสารนี้อธิบายว่าเราเก็บข้อมูลอะไรบ้าง เก็บทำไม ใช้งานอย่างไร และคุณมีสิทธิ์อะไรบ้าง เกี่ยวกับข้อมูลของคุณ ทั้งจากการใช้งานหน้าเว็บ (awesome-aqua.vercel.app) และการทักแชท ผ่าน Facebook Messenger

1. ข้อมูลที่เราเก็บ

ข้อมูลเก็บตอนไหนใช้ทำอะไร
Page-Scoped ID (PSID) เมื่อคุณทักแชทเพจ Awesome Aqua ผ่าน Messenger ระบุตัวตนผู้สนทนา เพื่อส่งข้อความตอบกลับให้ถูกคน (Facebook เป็นผู้ให้ ID นี้ ไม่ใช่ข้อมูลส่วนตัวที่ระบุตัวตนได้โดยตรง)
ตะกร้าสินค้า / ประวัติการสนทนาล่าสุด เมื่อคุณกด "เพิ่ม" ปลาเข้าตะกร้าผ่านบอท จดจำรายการที่คุณเลือกไว้ระหว่างสนทนา เพื่อสรุปยอดตอนสั่งซื้อ
ข้อมูลคำสั่งซื้อ (รายการปลา, ยอดรวม, สถานะ) เมื่อคุณยืนยันสั่งซื้อผ่านบอท บันทึกออเดอร์ ติดตามสถานะ ชำระเงิน/จัดส่ง
คุกกี้พื้นฐานของเบราว์เซอร์ เมื่อเข้าชมเว็บไซต์ จดจำภาษาที่เลือก (TH/EN) และรายการที่กด Wishlist ไว้ (เก็บในเบราว์เซอร์ของคุณเอง ไม่ได้ส่งเข้าเซิร์ฟเวอร์)

เราไม่เก็บข้อมูลบัตรเครดิต/บัญชีธนาคาร (การชำระเงินทำผ่านการโอนและแนบสลิป ซึ่งเป็นการสื่อสารโดยตรงระหว่างคุณกับแอดมิน ไม่ผ่านระบบอัตโนมัติของเรา) และไม่เก็บ ข้อมูลอ่อนไหวอื่นๆ เช่น ข้อมูลสุขภาพหรือศาสนา

2. เราใช้ข้อมูลของคุณอย่างไร

  • ตอบกลับข้อความและคำถามเกี่ยวกับสินค้าที่คุณทักเข้ามาผ่าน Messenger
  • ประมวลผลคำสั่งซื้อและติดต่อประสานงานเรื่องการชำระเงิน/จัดส่ง
  • แจ้งเตือนสถานะออเดอร์ (เช่น ยืนยันการชำระเงิน)
  • ปรับปรุงหน้าเว็บ/บอทให้ใช้งานง่ายขึ้น (วิเคราะห์ภาพรวมแบบไม่ระบุตัวตน เช่น ปลาที่มีคนดูเยอะ)

เราไม่ขายหรือแบ่งปันข้อมูลของคุณให้บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาด

3. ใครเข้าถึงข้อมูลของคุณได้บ้าง

  • แอดมิน/เจ้าของร้าน Awesome Aqua เท่านั้น (เข้าระบบหลังบ้านด้วยบัญชีที่มีสิทธิ์)
  • ผู้ให้บริการโครงสร้างพื้นฐานที่เราใช้งาน ได้แก่ Supabase (ฐานข้อมูล) และ Vercel (โฮสติ้ง) ซึ่งทำหน้าที่เป็นผู้ประมวลผลข้อมูลแทนเราตามนโยบายของผู้ให้บริการแต่ละราย
  • Meta/Facebook ในฐานะแพลตฟอร์มที่ส่ง-รับข้อความ Messenger (ตามนโยบายความเป็นส่วนตัวของ Meta)

4. สิทธิ์ของคุณ — ขอดู/ลบข้อมูล

ลบข้อมูลด้วยตัวเองในแชท: พิมพ์ "ลบข้อมูลฉัน" คุยกับบอท Awesome Aqua ได้ทุกเมื่อ ระบบจะลบตะกร้า/ข้อมูลการสนทนาล่าสุด และตัดการเชื่อมโยง PSID ออกจากคำสั่งซื้อเดิมทันที (ยังคงเก็บยอดขายไว้ในระบบบัญชีแบบไม่ระบุตัวตน เพื่อความถูกต้อง ทางการเงินของร้าน)

ลบผ่าน Facebook โดยตรง: คุณสามารถลบสิทธิ์ที่ให้กับ แอป "AwesomeAqua Bot" ได้จากการตั้งค่าบัญชี Facebook ของคุณเอง (Settings → Apps and Websites) ระบบของเราจะได้รับแจ้งอัตโนมัติและลบข้อมูลที่เกี่ยวข้องให้ทันที

หากต้องการสอบถามเพิ่มเติมเกี่ยวกับข้อมูลของคุณ หรือขอให้ลบข้อมูลกรณีอื่นๆ ติดต่อเราได้ที่ช่องทางในหัวข้อถัดไป

5. ระยะเวลาการเก็บข้อมูล

ข้อมูลตะกร้า/session การสนทนา จะถูกเก็บไว้ระหว่างที่คุณยังใช้งานอยู่ และจะถูกเคลียร์ เมื่อสั่งซื้อสำเร็จ หรือเมื่อคุณขอลบข้อมูลเอง ข้อมูลคำสั่งซื้อจะถูกเก็บไว้เพื่อวัตถุประสงค์ ทางบัญชี/ภาษีตามระยะเวลาที่กฎหมายกำหนด แม้จะตัดการเชื่อมโยงกับตัวตนของคุณแล้วก็ตาม

6. ความปลอดภัยของข้อมูล

  • ฐานข้อมูลเปิดใช้งาน Row Level Security (RLS) จำกัดสิทธิ์การเข้าถึงตามบทบาท
  • การเชื่อมต่อระหว่าง Messenger กับระบบของเรา ตรวจสอบลายเซ็นทุกคำขอ (HMAC signature) เพื่อยืนยันว่าข้อมูลมาจาก Meta จริง
  • สำรองข้อมูลอัตโนมัติทุกวัน เพื่อป้องกันข้อมูลสูญหาย
